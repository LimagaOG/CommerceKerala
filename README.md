# ForCommerceKeralaByRiswan-Limaga

A centralized repository featuring open-source desktop applications, accounting utilities, and digital tools designed specifically for higher secondary commerce education, teachers, and students in Kerala.

---

---

## 📦 How to Download & Run

1. Head over to the **[Releases](../../releases)** section of this repository.
2. Download the latest stable version .
3. Double-click the file to run it instantly—no complex installation or internet connection required!

---

## 🛠️ Tech Stack
* **Core:** HTML, CSS, JavaScript
* **Runtime / Framework:** Electron & Electron Builder
* **Build Target:** Standalone Portable Executable
